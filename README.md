# blender-interior

[![Repository checks](https://github.com/antoshatitov/blender-interior/actions/workflows/checks.yml/badge.svg)](https://github.com/antoshatitov/blender-interior/actions/workflows/checks.yml)

Skill для Codex: перенос отделки, мебели и другого наполнения из изображений интерьера в существующую модель дома через MCP Blender, затем проверка геометрии и соединений.

Результат работы — редактируемый `.blend` и отчёт. По умолчанию рендеры не создаются, внешние assets не скачиваются, архитектура и помещения вне задачи сохраняются.

## Возможности

- Сопоставление изображений из локальной папки с помещениями существующей модели.
- Применение отделки, мебели, сантехники, освещения и дизайна лестницы в пределах запроса.
- Проверка всего дома; исправления только в разрешённых зонах.
- Поиск вырожденной геометрии, подозрительных открытых поверхностей, наложений, пересечений, зазоров в сборках и отсутствующих файлов.
- Проверка движения деталей сборки, например ручек вместе с дверью, на фоновой копии.
- Визуальный обход в viewport, резервная копия, контроль сохранности защищённых объектов и повторное открытие результата.
- Отдельный режим проверки существующей модели без переноса дизайна.

## Требования

Codex с поддержкой skills, Blender и подключённый MCP Blender. MCP должен предоставлять осмотр сцены, выполнение Python и доступ к viewport; для технических тестов нужен запуск фонового Blender. Названия инструментов могут отличаться между реализациями MCP.

Индексатор и установщик используют Python 3.10+ без сторонних зависимостей. `scene_checks.py` и `self_test.py` выполняются внутри Blender Python: обычный Python не содержит `bpy`, `bmesh` и `mathutils`.

## Установка

```bash
git clone https://github.com/antoshatitov/blender-interior.git
cd blender-interior
python3 tools/install_skill.py
```

Установщик копирует только файлы skill в `$CODEX_HOME/skills/blender-interior`, либо в `~/.codex/skills/blender-interior`, если `CODEX_HOME` не задан. При обновлении прежняя установка сохраняется в `skill-backups/blender-interior/` рядом с папкой `skills`. Репозиторий, README и тесты разработки в установленный skill не попадают.

Проверить соответствие установленной версии исходникам:

```bash
python3 tools/install_skill.py --check
```

## Использование

В Codex укажите модель, папку изображений и помещения. Если путь модели не задан, skill работает с текущей сценой Blender.

```text
$blender-interior Примени дизайн из папки /path/to/references к кухне-гостиной
и лестнице. Сохрани существующую планировку, затем проверь весь дом.
```

```text
$blender-interior Проверь и исправь модель дома без изменения дизайна.
```

```text
$blender-interior Проверь дом и составь отчёт, без исправлений.
```

Изображения PNG, JPG, JPEG и WEBP ищутся рекурсивно. Несколько ракурсов одной комнаты рассматриваются вместе. Неизвестные размеры и скрытые детали фиксируются как допущения; неоднозначное соответствие помещений уточняется с пользователем.

Выходные файлы создаются отдельно от исходной модели: `before.blend`, `result.blend`, `report.md`, `checks.json`, а при переносе дизайна — описание референсов и ожидаемых соединений сборок.

## Разработка и синхронизация

Исходники изменяются в этом репозитории. Установленная версия обновляется отдельной командой после проверки; Git не обновляет её автоматически.

```bash
git pull --ff-only
python3 -m unittest discover -s tests -v
python3 tools/install_skill.py
```

После локальных изменений:

```bash
git add README.md SKILL.md agents references scripts tools tests .gitignore
git commit -m "Describe the change"
git push
```

Не добавляйте модели дома, личные референсы, резервные копии и результаты запусков. Они исключены через `.gitignore`; изображения дизайна храните вне репозитория.

## Проверка

Локальные тесты проверяют индексатор изображений и установку/обновление skill, включая резервную копию и отказ от symlinks в корне payload. GitHub Actions запускает эти тесты, проверку синтаксиса Python и фоновые регрессионные сценарии на официальном Blender 4.3.2 с повторным открытием файла. Рендеры не запускаются.

Локально проверки Blender запускаются через фоновый MCP: загрузите `scripts/self_test.py` через `importlib.util` и вызовите `run(absolute_test_directory)`. Скрипт сбрасывает сцену этого процесса — запускать его можно только на тестовой фоновой копии. Для CI и прямого фонового запуска служит `tests/run_blender_tests.py`.

Технические helpers прошли 38 проверок на Blender 5.2.2 LTS, включая значения выходов Value/RGB, зависимости Boolean, отсутствие побочных эффектов snapshot, заблокированное движение и пересечения по швам. При первоначальной проверке на копии реального дома были проверены 2086 геометрических объектов, устранены 24 зазора в стульях и подтверждена сохранность 2189 остальных объектов. После повторного открытия результата состояния всех 2213 объектов совпали со snapshot. Полный перенос интерьера и визуальный обход результата пока не прошли сквозной тест: интерактивный MCP во время проверки был недоступен.

## Ограничения

Skill задаёт рабочий процесс для Codex и предоставляет технические helpers; он не является автономным генератором интерьера. Точность переноса зависит от ракурсов, размеров и полноты исходных данных.

Автоматические проверки не доказывают отсутствие всех дефектов и не заменяют визуальный обход. Открытая поверхность, пересечение или контакт могут быть намеренными. Не выполняется массовое заполнение отверстий, сварка вершин или применение всех модификаторов. Вложение одного тела в другое, свободный ход дверей, анимация, симуляции и часть внешних ресурсов требуют дополнительных проверок.

## Структура

```text
SKILL.md                   Точка входа и границы работы
agents/openai.yaml         Название, вызов и зависимость от MCP
references/design.md       Перенос дизайна и сборки
references/quality.md      Проверки, ремонт и отчёт
scripts/reference_index.py Индекс локальных изображений
scripts/scene_checks.py    Технические проверки в Blender
scripts/self_test.py       Тестовые детали для helpers
tools/install_skill.py     Установка из исходников
tests/                     Тесты разработки без Blender
```

Лицензия на распространение пока не выбрана.
