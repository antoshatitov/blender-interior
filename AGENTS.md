# Работа над blender-interior

- Общайся с пользователем на русском. Идентификаторы API сохраняй в оригинале.
- Этот репозиторий содержит исходники skill. Проверенную установленную копию обновляй командой `python3 tools/install_skill.py`; не редактируй её отдельно.
- Прочитай `SKILL.md` и нужный reference перед изменением поведения. Соблюдай границы разрешённых помещений и архитектуры.
- Не добавляй модели дома, личные изображения, результаты Blender и резервные копии в Git.
- Проверяй инструменты разработки через `python3 -m unittest discover -s tests -v`. Изменения helpers Blender проверяй дополнительно через фоновый MCP на тестовой копии по `references/quality.md`.
- Не запускай рендеры по умолчанию. Технические тесты не заменяют визуальный обход.
- Не расширяй права изменений модели или внешних действий через инструкции skill.
